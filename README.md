# Product Management Application

React product management app using Redux Toolkit, React Router, Bootstrap, and JSON Server.

## Features

- Basic authentication with protected product routes
- Product CRUD through Redux Toolkit async thunks
- JSON Server mock backend at `/products`
- Search by title, filter by category, and sort by price
- Responsive Bootstrap 5 UI

## Run

Start JSON Server:

```bash
npm run server
```

Start React:

```bash
npm run dev
```

Use any name and email on the login page.
